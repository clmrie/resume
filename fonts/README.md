# Fonts

Latin Modern (`LM-*.woff2`) — the OpenType successor to Donald Knuth's Computer
Modern, which is the typeface `resume_CLEMENT_v2.tex` compiles to. Vendored here
so `index.html` matches the PDF without depending on a CDN.

- Latin Modern is released by GUST under the GUST Font License (GFL), a free
  licence permitting redistribution: http://www.gust.org.pl/projects/e-foundry/licenses
- These WOFF2 builds are taken from LaTeX.css (MIT):
  https://github.com/vincentdoerig/latex-css
